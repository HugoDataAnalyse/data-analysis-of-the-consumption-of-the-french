Key project highlights:Data Cleaning & Prep: Handling missing values, analyzing accounting entries, and applying grouped imputation by expenditure category (EXPENDITURE).

Descriptive Statistics: Visualizing overall macroeconomic temporal trends and deep-dive sector focuses (housing, financial services, etc.).

Inferential Statistics: Stationarity testing (Augmented Dickey-Fuller) and linear regression modeling (OLS) to capture long-term structural trends.
